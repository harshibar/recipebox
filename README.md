# 🍝 recipeBox

## [`sous/`](./sous) — cook-along logger *(active)*

Capture voice notes and photos while you cook, each stamped with how far into
the recipe you were, then file the timeline back to the recipe in **Obsidian**
or **Notion**. An installable web app — no build step, no dependencies.

```bash
cd sous && npm start
```

See [`sous/README.md`](./sous/README.md) for setup.

## Flutter app *(archived)*

The original recipeBox — a mobile app that stored and searched informal
recipes — is the Flutter project at the repository root. It is incomplete and
no longer builds: it pins Flutter SDK 2.6 and 2020-era Firebase packages, one
of which is a git dependency on a fork that has since moved on. It is kept for
reference. Feel free to fork it.
